# Балапан

Учебный проект «Балабақша қызметін басқаруға арналған веб-жүйе».
Интерфейс на казахском языке. Стек: Python, FastAPI, Jinja2, SQLite.

## Запуск в Windows

Запустите start.cmd и откройте http://127.0.0.1:8013.
При первом запуске приложение создаст balapan.db и заполнит её демонстрационными данными.
Для установки зависимостей требуется интернет, если они ещё не установлены.

## Демонстрация

1. На странице «Кіру» раскройте «Демо аккаунттар» и выберите «Ата-ана».
2. Создайте заявку через «Жаңа өтінім». Введите вымышленные данные ребёнка.
3. Выйдите и войдите как «Директор». Найдите заявку и выберите «Қабылдау».
4. Войдите как «Тәрбиеші» и поставьте отметку в журнале посещаемости.
5. Вернитесь в кабинет родителя и проверьте статус заявки и отметку за выбранный день.

Администратор также может создавать и редактировать группы и публиковать объявления.
Воспитатель видит детей закреплённых за ним групп. Родитель видит только свои заявки.

Демо-вход предназначен для локального учебного показа. Фото на главной: [Yan Krukau, Pexels](https://www.pexels.com/photo/two-boys-playing-with-wooden-blocks-in-a-room-8612970/).

## Дополнительные сценарии

- В кабинетах «Ата-ана» и «Тәрбиеші» ссылка «Күнделік» доступна у принятого ребёнка. Воспитатель заполняет дневник за выбранную дату, родитель читает записи.
- Родитель может предупредить об отсутствии сегодня или в будущем. Сообщение появится у воспитателя в журнале за выбранную дату. Отметка посещаемости выставляется воспитателем отдельно.
- В кабинете администратора отчёт «Топтардың қатысу есебі» показывает посещаемость каждой группы за выбранную дату.

## Карточки детей и расписание

- «Менің балаларым» показывает отдельную карточку каждого принятого ребёнка. Для проверки нескольких карточек отправьте ещё одну заявку от того же демо-родителя и примите её как директор.
- Воспитатель видит занятия на выбранный день в кабинете и полное расписание своих групп по ссылке «Сабақ кестесі».
- Директор видит сводный отчёт, создаёт, меняет и удаляет занятия. При сохранении проверяется пересечение занятий одного воспитателя.

## REST API директора

Войдите как «Директор» и откройте кнопку «REST API» в кабинете. Swagger UI загружается через интернет. После входа JSON можно открыть напрямую, в том числе без Swagger UI.

| Метод и путь после /api/v1 | Данные или действие |
| --- | --- |
| GET /groups | Группы и свободные места |
| GET /applications?state=pending | Заявки с фильтрами и пагинацией |
| PATCH /applications/{application_id} | Решение, например JSON `{"state":"accepted"}` |
| GET /attendance?day=2026-11-23&group_id=1 | Дневная сводка. Фильтр по группе необязателен |
| GET /attendance/period?start=2026-11-21&end=2026-11-23 | Сводка за 1–31 день, необязательный group_id |
| GET /schedule?group_id=1 | Расписание выбранной группы или всех групп |
| POST /schedule | Добавление занятия |
| PATCH /schedule/{lesson_id} | Изменение указанных полей занятия |
| DELETE /schedule/{lesson_id} | Удаление занятия |
| GET /events | Список мероприятий |
| GET /events/{event_id} | Детали мероприятия и ссылки на вложения |

API использует текущую сессию и доступен только директору. Swagger показывает схемы запросов и ответов. PATCH заявки и POST/PATCH/DELETE расписания изменяют общую базу сайта. Схема OpenAPI доступна по адресу /api/openapi.json.

## Распорядок и мероприятия

- «Топтар» и «Тәрбиешілер» открываются как отдельные страницы.
- «Күн тәртібі» подбирает распорядок по возрасту группы. Родитель видит группы принятых детей, а гостю доступны три возрастных примера.
- Карточки объявлений ведут на страницу мероприятия. Директор может публиковать и редактировать детали, добавлять JPG/PNG до 5 МБ и MP4/WebM до 25 МБ. Загруженные файлы хранятся в event-media рядом с базой. Страницы мероприятий и вложения видны посетителям сайта.

### Запуск после скачивания исходников

Распакуйте ZIP целиком и запустите start.cmd на компьютере с установленным Python.
При первом запуске приложение создаёт SQLite-базу и три демо-аккаунта автоматически.
Откройте http://127.0.0.1:8013/kiru и выберите роль в разделе «Демо аккаунттар».
Для ручного входа используйте parent@balapan.test, teacher@balapan.test или admin@balapan.test.
Общий пароль локальных демо-аккаунтов: Balapan2026!
